# CheckMyStars ⭐

Site officiel de CheckMyStars - Application de gestion d'inspections et de notation de biens d'hébergement.

## 📋 Description

CheckMyStars est une application web développée pour faciliter la gestion des inspecteurs et la notation de différents types de biens d'hébergement (Airbnb, hôtels, campings). L'application permet un suivi rigoureux des inspections et une évaluation standardisée des établissements.

## ✨ Fonctionnalités principales

- 🧾 **Gestion des devis et factures** : Création,modification et suivi des factures
- 👤 **Gestion des inspecteurs** : Création, modification et suivi des comptes inspecteurs
- 🏨 **Notation des biens** : Évaluation standardisée des hébergements
- 🏠 **Multi-types** : Support pour Airbnb, hôtels et campings
- 📊 **Suivi des inspections** : Historique et rapports d'évaluation

## 🚀 Technologies utilisées

- **Frontend** : HTML5, CSS3, JavaScript
- **Backend** : PHP, MARIADB
- **Serveur** : Apache/Nginx (compatible)

## 📦 Prérequis

- PHP 7.4 ou supérieur
- Serveur web (Apache, Nginx, ou XAMPP/WAMP pour le développement local)
- Navigateur web moderne

## 🔧 Installation

### Méthode : Serveur local (XAMPP/WAMP)

```bash
# 1. Cloner le repository
git clone https://github.com/JeanClanche/CheckMyStars.git

# 2. Déplacer le projet dans le dossier du serveur
# Pour XAMPP : déplacer dans htdocs/
# Pour WAMP : déplacer dans www/

# 3. Démarrer le serveur local

# 4. Accéder à l'application
# http://localhost/CheckMyStars
```

## Utilisation

1. Accéder à l'application via votre navigateur
2. Se connecter avec un compte inspecteur
3. Créer ou gérer des inspecteurs
4. Effectuer des notations de biens d'hébergement
